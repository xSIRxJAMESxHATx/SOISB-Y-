# SO!SB!Y! Branding Guide

## Name
**SO!SB!Y!** — Superb Owl! Super Browns! Yeah!

## Mascot
**Superb Owl** — crown, monocle, championship swagger, Cleveland energy.

### Logo usage
| Asset | Path | Use |
|-------|------|-----|
| Full poster | `assets/superb_owl_logo.png` | Hero, about, social |
| Icon | `assets/superb_owl_icon.png` | Header, sidebar |
| Favicon | `assets/favicon.png` | Browser tab |
| Icon set | `assets/icons/*` | PWA / homescreen |
| Brand pack | `assets/branding/*` | Marketing |

### Favicon design
Simplified **head + crown + monocle**, high contrast, orange/brown. No football, cigar, or text.

## Colors
| Token | Hex |
|-------|-----|
| Primary orange | `#FF5A00` |
| Secondary orange | `#FF8C29` |
| Dark brown | `#4A2A12` |
| Cream | `#FFF8EF` |
| Gold | `#E7B100` |

Team pages still override accents with team colors (Browns orange/brown, Guardians navy/red, etc.).

## Typography
UI: Outfit / system-ui. Scores: JetBrains Mono.

## Voice
Friendly Cleveland slant, optimistic, never mean-spirited. Educational on betting tools.
